# RadEcho — Issue Tracker

**RadEcho** is a rebuild of Weather Underground's beloved (and long-discontinued) **RadBlast** radar tool — hyper-local, animated NEXRAD radar loops, station lookup or lat/lon pinpoint, no ads, no nonsense.

### 📡 Try the app

**https://radar.socialvinyl.app/viewer.html**

This is a personal project for a small group of friends, not a commercial product — but it's built to real engineering standards, and your reports genuinely help shape what gets built next.

## Reporting a bug or requesting a feature

The easiest way: use the **Report an issue** / **Request a feature** buttons right in the app. They open a short form, auto-attach the useful technical context (station, zoom level, browser info) and an optional screenshot, and file the issue here for you.

Prefer to write it up yourself? Feel free to open an issue directly on this repo instead — either way works.

## What happens after you file one

Every issue here is actively triaged. When something's fixed or a feature ships, the issue gets closed with a note on what changed — so you can track status right from this page without needing any special access.

## A couple of things worth knowing

- This repo is intentionally just an issue tracker — there's no source code here.
- If you're not on GitHub, no problem — the in-app form also takes just a name and email.

Thanks for kicking the tires. 🌩️
